# Gul Khan Restaurant NFC Landing Page

GitHub Pages-ready website for Gul Khan Restaurant, Oud Metha.

## Main files
- `index.html` — landing page
- `style.css` — page styling
- `logo.png` — restaurant logo
- `background.png` — page background
- `gul-khan-menu.pdf` — complete 9-page menu PDF

The **VIEW MENU** button opens `gul-khan-menu.pdf`.
The **LEAVE A REVIEW** button opens the supplied direct Google review page.

## GitHub Pages
Upload the files to the repository root, then enable GitHub Pages from the `main` branch and `/ (root)`.
